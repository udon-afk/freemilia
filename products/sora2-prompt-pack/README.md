# Sora2 Story Prompt Pack (25/50/75 sec)

更新日: 2026-03-19

このパックは、**知識依存の紹介系を避けたストーリー特化**のSora2用プロンプト集です。

## 仕様
- 形式: 縦動画 9:16
- 尺: **25秒 / 50秒 / 75秒**（10n+15n秒ルール準拠）
- 路線: 動物キャラ × 親しみストーリー

## ファイル
- `viral-genre-research.md` : ニッチ整理
- `sora2-prompts.md`       : ストーリー型プロンプト12本

## 使い方
1. `sora2-prompts.md` からテーマと尺を選ぶ
2. 変数テンプレの `{}` を埋める
3. まず25秒で検証
4. 当たりだけ50/75へ展開
