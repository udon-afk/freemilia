# Verification Checklist (Pre-packaging)

目的: 導入済み環境バイアスを避け、初見ユーザー視点で再現性を検証する。

## 0. テスト前提
- 既存運用とは別ディレクトリで実施
- 既存設定ファイルを直接使わない
- このパックのガイド/テンプレだけで進める

## 1. 擬似クリーン環境準備（5分）
- [ ] `sandbox-test/` を新規作成
- [ ] パック内ファイルだけを `sandbox-test/` に配置
- [ ] 既存の実運用ファイルを参照しないことを確認

## 2. 初見セットアップ再現（15〜30分）
- [ ] `customization_guide.md` を上から順に実行
- [ ] 必須置換項目を全て埋める
  - [ ] `{{DISCORD_CHANNEL_ID}}`
  - [ ] `{{MODEL_ALIAS}}`
  - [ ] `{{WORKSPACE_PATH}}`
  - [ ] `{{SCHEDULE_EXPR}}`
  - [ ] `{{PRODUCT_LINK}}`
- [ ] 途中で「次に何するか」が迷わない

## 3. 動作確認（10分）
- [ ] 3時間ダイジェスト形式のサンプル出力が作れる
- [ ] 投稿テンプレ（note/BOOTH）がそのまま使える
- [ ] エラー時の復帰手順でリカバリできる

## 4. 品質ゲート（販売前）
- [ ] 初回実行まで30分以内
- [ ] 置換漏れゼロ
- [ ] つまずきポイント3件以内
- [ ] FAQ/手順に修正反映済み

## 5. 失敗ログ（必須記録）
- 詰まった手順:
- エラーメッセージ:
- 原因:
- 修正内容:
- 再発防止:

## 判定
- PASS: 主要手順が初見で再現可能（30分目安）
- CONDITIONAL PASS: 軽微な修正で再現可（修正後に再テスト）
- FAIL: 手順/テンプレ構造を再設計
