# コンテンツ運用KPI＆振り返りシート v1.0.0

数字で振り返る。感覚に頼らない。

## これは何？
note・BOOTH・SNSを運用している個人〜小規模チーム向けの、
**KPI記録・振り返り・改善サイクル**を仕組み化するテンプレート集です。

## 同梱内容
- **5種類のテンプレート**
  - 週次KPI記録シート
  - 月次振り返りシート
  - コンテンツカレンダー（月間投稿計画）
  - A/Bテスト記録シート
  - 四半期目標設定シート（OKR風）
- **記入例 2本**
- **活用ガイド**（いつ何を記録するか・指標の読み方）

## 使い方
1. まず weekly-kpi-sheet.md を毎週コピーして記録開始
2. 月末に monthly-review.md で振り返り
3. 四半期ごとに quarterly-goals.md で目標更新

## 対応エディタ
Markdown対応エディタならどれでもOK（Notion / Obsidian / VSCode / テキストエディタ）
