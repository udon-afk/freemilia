# 【コンテンツ運用KPI＆振り返りシート】数字で伸ばす仕組みを作る

## これは何？
note・BOOTH・SNSの運用、「感覚」で続けていませんか？

このテンプレート集は、**記録→振り返り→改善**のサイクルを仕組み化するためのシートです。
「何が効いて、何が効いてないか」を数字で判断できるようになります。

## 同梱テンプレート（5種類）
📊 **週次KPI記録シート** — 毎週10分で数字を記録
📝 **月次振り返りシート** — 今月の成果と改善を整理
📅 **コンテンツカレンダー** — 月間の投稿計画を立てる
🔬 **A/Bテスト記録シート** — 仮説→検証→学びを残す
🎯 **四半期目標設定シート** — OKR風の目標管理

## さらに付属
📝 **記入例 2本** — 実際に埋めたサンプル
📖 **活用ガイド** — いつ何を記録するか・指標の読み方

## 特徴
- Markdown形式、コピペですぐ使える
- Notion / Obsidian / VSCode 等で使用可能
- 初心者向けの指標解説付き
- 「全部埋めなくてOK」設計（続けることを最優先）

## こんな方に
- 投稿は続けているけど「伸びてるか分からない」
- 数字を見る習慣をつけたい
- 改善サイクルを仕組み化したい
- 週1回10分で運用を振り返りたい
