# HEARTBEAT.md

## Revenue production heartbeat policy

On heartbeat polls:
1. Focus on low-maintenance sellable items (passive-sale style).
2. Keep execution lightweight, but report in 3-hour batched thinking.
3. If current production is blocked, output:
   - stop reason
   - concrete next task text to assign
   - one pivot option
4. Prefer creating reusable digital assets (templates/checklists/prompts/guides).
5. Avoid system-level changes unless explicitly approved.
