# HEARTBEAT.md

## Team feature planning loop (active)

On each heartbeat poll, do the following quickly and consistently:

1. Generate a compact planning update for the engineering team with:
   - Candidate apps / useful feature ideas (max 3)
   - Prioritize items that can lead to monetization (direct revenue, lead-gen, paid automation, recurring value)
   - For each: expected impact, implementation effort (low/med/high), risk (low/med/high)
   - One "today-startable" task (smallest executable next step)
2. Only post digest updates to Discord channel `1478007786385182892` once every ~3 hours (batching).
   - Heartbeat execution can stay frequent (e.g., 30 min), but message posting must be batched to reduce noise/context.
3. Keep wording concise and execution-oriented (no long essays).
4. If there is no meaningful new proposal for the 3-hour digest window, post a short status-only note (what was checked + why no update).

## Safety/operation

- Do not auto-apply high-risk changes.
- Stay in proposal mode unless explicit permission is given.
- If tools fail, report failure reason and a retry instruction in the same channel.
