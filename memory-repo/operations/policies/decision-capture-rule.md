# Decision Capture Rule（決め事のGitHub参照化ルール）

更新日: 2026-03-27

## 目的
会話で決まった方針・運用ルールを流さず、必ず参照可能な形で残す。

## 適用対象
- 役割分担の変更
- 運用フロー変更（トリガー、報告、承認）
- コンテンツ戦略の方針変更
- 新しい委任・分業ルール

## 基本ルール
1. 決定後、**同セッション内で即ファイル化**する。
2. 保存先は `memory-repo/operations/` 配下（strategy/policies/reports のいずれか）
3. ファイル名に日付を入れる（例: `...-2026-03-27.md`）
4. Git commit + push まで完了して初めて「保存済み」とする。
5. ユーザーへは **ファイルURL + commit URL** をセットで返す。

## 最小テンプレ
- 背景
- 決定事項
- 適用範囲
- 次アクション
- 見直し条件

## 例外
- 一時的な雑談のみの合意は保存不要
- 外部公開や課金等の重大事項は承認後に確定版保存
