# AiToEarn 導入可否メモ（2026-03-25）

対象: https://github.com/yikart/AiToEarn

## 結論（先に）
- **導入は技術的に可能**
- ただし、現行運用へ**即本番投入は非推奨**
- 先に隔離環境で PoC を実施すべき

## 可否判定
- 可: Dockerベースで立ち上げ確認、UI確認、単一機能PoC
- 条件付き可: 投稿連携機能（APIキー・トークン・規約確認前提）
- 不可（現時点）: 本番アカウントへ即接続して24/7自動配信

## 主なリスク
1. 外部投稿系の権限管理が重い（誤投稿・凍結リスク）
2. API課金が読みにくい（複数プラットフォーム連携時）
3. 既存OpenClaw運用との責務重複（どっちが司令塔か曖昧になる）
4. 監視・復旧運用が未整備だと停止時の復帰が遅い

## 推奨導入順（最小）
1. 隔離検証環境で起動（本番VPSとは分離）
2. 投稿機能は無効で、まず情報収集/ドラフト機能のみ確認
3. 単一チャネルでPoC（1日1回、手動トリガー）
4. ログ監視・失敗時復旧フローを確立
5. 問題なければ段階的に本番導入

## 今回の判定（udon運用向け）
- 今の優先: ClawHub強化 + OpenClaw自律化
- AiToEarnは「即本番」ではなく「並行PoC」枠で扱うのが最適
