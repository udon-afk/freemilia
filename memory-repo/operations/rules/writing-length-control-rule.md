# 文章生成時の文字数管理ルール

更新日: 2026-03-24

## 目的
文字数指定がある文章タスクで、生成後に必ず文字数検証を行い、基準未達を防ぐ。

## 適用条件
- 文章作成タスク
- かつ、文字数指定（例: 導入2000字 / 本文3000字）がある場合

## 必須手順
1. 指定文字数に合わせて章ごとに分割して生成する
2. 生成後、`scripts/count_chars.py` で文字数を計測する
3. 未達の場合は不足章を追記して再計測する
4. 目標達成後に納品する

## 計測コマンド
```bash
python3 /root/.openclaw/workspace/scripts/count_chars.py <target_file>
```

## 判定基準
- 既定は「空白込み文字数」を基準にする
- 指示がある場合のみ別基準（空白除外など）に切り替える

## 運用メモ
- 一括生成より、章単位生成の方が文字数ブレが少ない
- 不足分は「実例・失敗例・改善策・再発防止」で補う
