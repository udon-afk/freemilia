# OpenClaw向け：副業マネタイズ戦略・完全インストール要件

## ■ プロジェクトの最終目標
- フェーズ1: 知識ゼロ・実績ゼロからの「0→1（初報酬）」達成。
- フェーズ2: サブスク代を賄うための「月3万円」の安定したキャッシュフロー構築。
- リソース: 1日5〜10時間の圧倒的な作業時間、一般以上の高度なAIスキル（OpenClaw、Claude Code等の操作・開発）。
- 制約事項: 営業（特定個人へのアプローチ）はしない。AI以外の分野（動画編集、ハンドメイド等）には手を出さない。

## ■ 基本戦略：「AIオタクの熱量をそのまま売る」
他業界の悩みを探すのではなく、「AIの凄さは知っているが自分では組めない非エンジニア」や「数ヶ月前の自分（初心者）」をターゲットにする。最新のAI技術や便利な自動化スクリプトを「時短のツルハシ（ショートカット）」として販売する。

## ■ 主戦場（プラットフォーム）
- 販売拠点: note（価格帯：500円〜1,500円）
  - 理由：心理的ハードルが低く、衝動買いを誘発しやすいため。まずはここで「自分のコードがお金に変わる」体験を積む。
- 集客拠点: X（旧Twitter）
  - 理由：視覚的なインパクト（GIFやスクショ）でバズを狙い、noteへ誘導するため。

## ■ 商品の形態（何を売るか）
以下のいずれかをnoteの有料記事としてパッケージ化する。
- 環境構築＆コピペ自動化ノウハウ: 初心者向けに、Claude Code等で自動化ツールを作るための噛み砕いた手順とコピペ用コード。
- 開発補助ツール: 個人開発者向けに、エラー解決プロンプトやAPI連携のGASスクリプトなど、自分が使って便利なもの。
- 最速検証レポート: 最新AIリリース時に最速で触り倒し、具体的な活用プロンプトと実装コードをまとめたカンニングペーパー。

## ■ note記事の「売れる黄金構成」（※OpenClawは今後この型で出力すること）
記事を執筆する際は、単なる技術ドキュメントではなく、読者の「感情」を動かし「時短」を売る構成にする。
1. 強烈なHook（無料エリア）: 技術的な前置きは排除。「〇〇を使って、××の作業を3秒で終わらせる魔法を作りました」という結論から入る。※ここにユーザーが用意したGIF/スクショが入る想定。
2. Before/Afterの絶望と希望（無料エリア）: 「手作業だと〇時間かかる絶望」と「このコードなら一瞬で終わる希望」を対比させる。
3. 裏側の仕組みのチラ見せ（無料エリア）: 使用技術（OpenClawやAPI等）を軽く触れ、権威性を出す。
4. 有料の壁（Paywallの宣言）: 「ここから先は、自分でゼロから組むのが面倒な人向けのコピペ用ショートカットです」と明言する。
5. 完全コード＆手順（有料エリア）: コピペ用コード、環境構築の完全手順、エラー時の対処法を網羅する。

## ■ ユーザー（あなた）の行動フロー
1. 【開発】AIに没頭し、「これ便利だ」「面白い」と思うコードやプロンプトを作る。
2. 【記録】それが動いている画面をGIF動画やスクショで保存する。
3. 【指示】OpenClawに対し、要点（何のツールか、どんなコードか）を投げ、「黄金構成でnoteの下書きを作れ」と指示する。
4. 【魂の注入】OpenClawが生成した下書きに対し、ユーザー自身が「マジでヤバい」「徹夜した甲斐があった」などの生身のオタクとしての熱量・感情をテキストに加筆する（※ここが一番重要）。
5. 【公開＆集客】noteで有料公開し、XでGIF動画とともに「ヤバいのできた。コードはnoteに置いとく」とポストして誘導する。
