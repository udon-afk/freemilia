## 下書き①（Mon分）

### タイトル案
- 毎朝30分を取り戻す。ニュース収集とタスク整理を“ほぼ自動”にした方法
- 情報収集が続かない人向け：朝の準備を自動化して1日を軽くする手順

### 導入（無料）
毎朝、ニュースを追って、今日やることを整理して、メモを作る。
この作業、真面目にやるほど時間が溶けます。

私も以前は「情報を追うだけで疲れる」状態でした。
でも今は、朝に必要な情報がまとまり、今日の優先タスクまで見える状態を、ほぼ自動で作っています。

結果として、朝の準備時間が約30分短くなり、着手が早くなりました。

### Before / After（無料）
**Before**
- ニュースサイトを手で巡回
- 気になった記事をメモに転記
- 今日のタスクを頭で整理
- 途中で別作業に逸れて未完了

**After**
- 朝にニュース要点がまとまって届く
- その日のタスク状況がすぐ見える
- 迷い時間が減って、最初の1手が早い

### 仕組みの概要（無料）
やっていることは難しくありません。

1. 朝の定時で情報収集を走らせる
2. 重要ポイントを短く整理する
3. その日のタスク状態と合わせて表示する
4. 画面上で確認→必要なら手動実行

要は「見る」「整理する」「次を決める」を分解して、自動化できるところだけ任せています。

- 投稿が続かない人向け。下書き→確認→公開準備までを仕組み化した話
- 「やる気に頼らない」個人運用術：投稿作業を止めない最小システム

### 導入（無料）
副業や発信って、ネタ切れより先に「運用疲れ」で止まります。

- 何を書くか迷う
- 途中で面倒になって先送り
- 気づけば未投稿のまま日が終わる

この流れを断ち切るために、私は「投稿そのもの」ではなく、
**投稿までの工程**を仕組み化しました。

### Before / After（無料）
**Before**
- アイデアがあっても下書きが始まらない
- 途中で構成が崩れて消耗
- 公開準備まで辿り着かない

**After**
- テーマ候補が先に並ぶ
- 下書きテンプレで着手が早い
- 公開前チェックが定型化される

### 仕組みの概要（無料）
1. テーマを先に候補化
2. 下書きテンプレで最初の文を機械的に作る
3. 最終確認ポイントを固定（誤字・導線・CTA）
4. 公開待ちキューに積む

この順番にすると、気分に左右されずに回せます。
