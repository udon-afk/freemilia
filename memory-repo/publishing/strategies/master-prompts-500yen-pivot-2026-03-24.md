# 500円商品向けピボット：マスタープロンプト集

更新日: 2026-03-24
方針: 「コードを売る」ではなく「コピペでAIに作らせる指示書」を売る。
対象: OpenClaw/Claudeを触る初中級者（環境差分で詰まりやすい層）

---

## 商品コンセプト

- 商品名案: **「コピペで動く：自動化ツール生成マスタープロンプト集（500円）」**
- 提供価値: 環境が違っても、AIにその場で最適コードを作らせる
- 売り文句: 「実装力じゃなく、指示力で自動化を最短で作る」

---

## 使い方（購入者向け）

1. プロンプトをコピペ
2. 自分の環境情報だけ差し替え
3. AIに投げる
4. 出力をそのまま実行
5. 失敗したら「修正プロンプト」を投げる

---

## マスタープロンプト1：要件整理→実装計画

```text
あなたは実装担当のAIエージェントです。以下の条件で、最短で動く実装計画を作成してください。

# 目的
{何を自動化したいか}

# 環境
- OS: {Linux/Windows/macOS}
- 実行場所: {VPS/ローカル}
- 利用可能ツール: {OpenClaw/Claude Code/Python/Node}
- 制約: {公開不可/ローカル限定/承認必須操作 など}

# 出力形式
1. 実装ステップ（5〜10手順）
2. 失敗しやすい点
3. 最小構成で先に動かす方法
4. 完了確認コマンド
```

---

## マスタープロンプト2：コピペ実装生成（本体）

```text
以下の要件を満たす「そのままコピペで実行できる」実装を作ってください。

# 要件
{例: 毎朝7時にAIニュースを収集して日本語要点を保存し、Webで閲覧可能にする}

# 環境情報
- サーバ: {VPS情報}
- 言語: {Python or Node}
- 実行: {systemd / cron / 手動}
- Webポート: {18080など}

# 重要
- ファイル作成先を明記
- 実行コマンドを [VPS] / [実機] で分ける
- 失敗時の復旧コマンドも書く
- セキュリティ上危険な設定は回避

# 出力
- 完成コード
- 設定手順
- 動作確認手順
```

## マスタープロンプト4：記事化（魂入り）

```text
次の条件でnote記事の下書きを作成してください。

# 条件
- 導入は体験談ベースで熱量を出す
- 読者は非エンジニア寄り
- 「今すぐ何をすればいいか」が伝わる構成
- 途中に無料/有料の境界を明示
- 有料部分はコード・手順・スクショ前提で具体化
- 全文4000字以上

# 素材
{実装ログ/失敗談/結果}
```

目標: 全文4000字以上

# 出力
