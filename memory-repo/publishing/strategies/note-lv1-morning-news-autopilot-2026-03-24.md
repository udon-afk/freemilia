## 0. 先に約束
この記事は「概念の話」を最小限にして、
**購入者がそのまま手を動かせば朝ニュース自動化が動く**ことを目的に書いています。

なので、構成はこの順です。

1. 失敗しない準備確認
2. 実際の設定コマンド
3. 動作確認
4. 失敗時の直し方
5. 毎日どこを見ればいいか

「とりあえず動かしたい」人は、上から順番にやってください。

## 1. このガイドの前提

- OpenClawが導入済み
- OpenClawコマンドが使える
- Discord等の送信先チャンネルを1つ決めている
- タイムゾーンは Asia/Tokyo を使う

> 本記事は「導入方法」ではなく「導入後の最初の自動化」を扱います。

## 2. まず5分でやる初期確認（ここを飛ばさない）

### [VPS] 2-1. OpenClawが生きているか
```bash
openclaw status
```

期待する状態：
- エラーで落ちていない
- cronが使える状態

### [VPS] 2-2. Gateway状態
```bash
openclaw gateway status
```

もし止まっていたら：
```bash

```

### [VPS] 2-3. 既存cron一覧を見る
```bash
openclaw cron list
```

ここで既存ジョブと衝突しない名前を決めます。

## 3. 今日中に動かすニュース自動化（本体）

ここからが実装手順です。  
今回は「毎朝7:10 JSTにニュース要約を送る」ジョブを作ります。

### [VPS] 3-1. ジョブを作成
```bash
openclaw cron add \
  --name "daily-ai-news-lv1-0710" \
  --cron "10 7 * * *" \
  --tz "Asia/Tokyo" \
  --session isolated \
  --agent main \
  --message "過去24時間の主要AIニュースを3〜5件収集し、日本語で要点を短くまとめて報告。各項目に(1)何が起きたか(2)なぜ重要か(3)次アクションを含める。" \
  --announce \
  --channel discord \
  --to 1473005686257483826 \
  --json
```

> `--to` は自分の配信先チャンネルIDに変更してください。

### [VPS] 3-2. 作成確認
```bash
openclaw cron list
```

確認ポイント：
- `daily-ai-news-lv1-0710` がある
- enabled が true
- 次回実行時刻が出ている

### [VPS] 3-3. 手動テスト実行（超重要）
```bash
openclaw cron run $(openclaw cron list | awk '/daily-ai-news-lv1-0710/{print $1}')
```

> awkが難しければ、`cron list` でIDを見て直接 `openclaw cron run <ID>` を実行。

## 4. 成功判定（これを満たせば“動いた”）

以下3つが揃えば成功です。

1. 対象チャンネルにニュース要約が届く
2. `openclaw cron runs --id <JOB_ID> --limit 5` で status=ok
3. 翌日の scheduled time に自動実行される

### [VPS] 実行履歴確認
```bash
openclaw cron runs --id <JOB_ID> --limit 5
```

## 5. ここでハマる（実際によくある失敗）

### 失敗A：ジョブはあるのに配信されない
原因候補：
- `--announce` なしで作っている
- 配信先 `--to` が誤り

対処：
- ジョブを edit か作り直し
- 実行履歴の deliveryStatus を確認

### 失敗B：手動では成功、定時で失敗
原因候補：
- タイムゾーン設定ミス
- 実行時刻競合（他ジョブと重なる）

対処：
- `--tz Asia/Tokyo` を明示
- 07:00ちょうどではなく07:10などにずらす

### 失敗C：gateway closed / 接続エラー
原因候補：
- Gatewayプロセス断

対処：
```bash
openclaw gateway restart
openclaw gateway status
```

### 失敗D：内容が薄い・読みにくい
対処：
- messageを修正して出力形式を固定
- 「何が起きた/重要性/次アクション」を必須化

## 6. 出力品質を上げるテンプレ（そのまま使える）

ジョブメッセージは、次のように“型”を強制すると安定します。

```text
過去24時間の主要AIニュースを3〜5件収集し、日本語で報告。
各ニュースは次の形式で出力：
- タイトル
- 何が起きたか（1〜2文）
- なぜ重要か（1文）
- 明日やるべきこと（1文）
最後に全体まとめを3行で付ける。
```

これだけで、情報の粒度が揃います。

---

## 7. 毎日やること（1分運用）

毎日チェックするのはこの3点だけ。

1. 今日のニュースが届いたか
2. 実行履歴が status=ok か
3. 明日の nextRun が見えてるか

### [VPS] 1コマンド確認
```bash
openclaw cron list && openclaw cron runs --id <JOB_ID> --limit 1
```

## 8. 追加で強くするなら（次の一歩）

朝ニュースが安定したら、次はこの2つ。

- 8-1. 日本語詳細解説ページを作る
  - タイトルだけでなく要点も読めるようにする
- 8-2. 手動再実行ボタンをWebに置く
  - 失敗時の復旧時間を短縮

> まずは1本を完璧に。機能はその後で増やす。

## 9. この設計が初心者向けに強い理由

- 最初から全部自動化しない
- 1ジョブに絞って成功体験を作る
- 失敗時の戻り方を先に用意する

導入直後に必要なのは“すごい構成”ではなく、
**毎日確実に動く最小構成**です。

この1本が回れば、OpenClaw運用の土台ができます。
