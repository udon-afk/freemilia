# MONEY_PRICE_TEST_MATRIX_V0

最終更新: 2026-03-10 22:21 JST
対象商品: OpenClaw Heartbeat収益化テンプレ Starter

## 1. 価格別ポジショニング（初版）

- **980円（低価格トライアル）**
  - 狙い: 購入心理ハードルを最小化してCVR重視
  - 期待: 初速の購入数は伸びやすい
  - 懸念: 安売り認知でサポート期待値との乖離が起きやすい

- **1,480円（基準価格）**
  - 狙い: 手に取りやすさと「実用パック感」のバランス
  - 期待: CVRと粗利の均衡が取れる本命帯
  - 懸念: 980円との差分価値を説明しないと中途半端に見える

- **1,980円（価値訴求型）**
  - 狙い: 時間短縮・失敗回避価値を前面に出して単価重視
  - 期待: 成約数は落ちても売上総額の上振れ余地
  - 懸念: サンプル品質・実績文脈が弱いとCVR低下

## 2. 判定軸（heartbeat検証用）

- 30秒理解率（誰向け/何が得られるか）
- 想定CVR（低/中/高）
- 1件あたり期待粗利（相対）
- サポート負荷リスク（低/中/高）
- 値上げ/値下げしやすさ

## 4. 初期結論

- **初回販売価格は1,480円を採用**（バランス最良）
- 980円は「初回限定/早期購入」施策の候補として保持
- 1,980円はサンプル強化（中身公開・実行例）後に再テスト
